Clavier

Sélectionnez d'abord un champ sur le téléviseur. Caractères ASCII uniquement : les accents sont retirés (é devient e).

Mes photos

Après l'importation, le fond d'écran passe sur « Mes photos ». Le téléviseur enregistre les photos en 1920×1080. La source du fond d'écran se choisit sur le téléviseur (Réglages de l'accueil → Fond d'écran et cadre photo, ou la tuile Fond d'écran).

Liens d'images personnalisés

L'adresse d'une image, une API d'images aléatoires qui renvoie une nouvelle image à chaque fois, ou une page / un JSON qui liste des adresses d'images. Le téléviseur les récupère une fois par jour et garde quelques images par lien.

Logo

La carte-titre et le film de démarrage intégrés au téléviseur : ceux de canvasOS, ou ceux de l'Apple TV. Ils servent d'icône aux réglages et d'animation de démarrage, sauf choix contraire ci-dessous.

Profils

La photo de chaque profil en haut à droite de l'accueil. Sans photo, le profil montre l'initiale de son nom sur sa couleur ; une photo est recadrée en carré, centrée. Le nom et la couleur se changent sur le téléviseur (Réglages de l'accueil → Profils).

Météo

La température s'affiche à côté de l'horloge de l'accueil, et les prévisions sur cinq jours dans le Centre de contrôle (bouton Météo). Prévisions d'Open-Meteo ; tant qu'aucune ville n'est choisie, le téléviseur devine le lieu une fois d'après son adresse IP publique (ip-api.com).

Paroles

Quand une app lit de la musique, une capsule en haut à gauche de l'accueil montre la pochette, le titre et l'artiste. À chaque nouveau titre, le téléviseur demande à LRCLIB, une base ouverte et gratuite (aucune clé ni aucun compte à créer), s'il a ses paroles : il envoie le titre, l'artiste, l'album et la durée du morceau, rien d'autre, et n'enregistre rien. Quand LRCLIB en a, sélectionnez la capsule avec la télécommande : un bouton Paroles sort à sa droite, OK affiche les paroles synchronisées sur le fond assombri (la ligne chantée s'éclaire et défile), OK encore les retire. Sans paroles synchronisées, le bouton n'apparaît pas. Désactivées, rien n'est envoyé à LRCLIB.

Top Shelf (TMDB)

Avec une clé, le Top Shelf de Netflix, Prime Video, Disney+, Apple TV, Max, Paramount+, Canal+ et Crunchyroll affiche les titres populaires de la semaine sur ce service en France (quand l'app ne publie pas de ligne « Continuer à regarder », ou si celle-ci est désactivée). Clé gratuite : themoviedb.org/settings/api (la « clé d'API » ou le « jeton d'accès en lecture »). La clé est enregistrée sur le téléviseur uniquement.

Fond d'écran Unsplash

La source « Unsplash » du fond d'écran puise dans les sélections éditoriales Fonds d'écran et Nature d'Unsplash, en 4K sur un téléviseur 4K. Clé gratuite : unsplash.com/developers (créez une app et copiez l'« Access Key » ; 50 requêtes par heure suffisent largement). La clé reste sur le téléviseur.

Sur l'écran d'accueil du téléphone

iPhone : Partager → Sur l'écran d'accueil. Android : menu ⋮ → Ajouter à l'écran d'accueil. L'icône garde le code actuel de la page : elle ne fonctionnera plus après « Régénérer le code » sur le téléviseur.

Apps de l'accueil

Chargement…

Touchez un nom pour le modifier ; videz-le pour reprendre le nom d'origine. « Ouvrir » lance l'app, ouvre le dossier ou passe sur l'entrée HDMI sur le téléviseur (hors de l'accueil canvasOS, une app demande le débogage local) ; les dossiers et les entrées se renomment et se rangent sur le téléviseur. Une image en paysage 16:9 convient le mieux : le téléviseur la recadre au centre (20 Mo au maximum). Sur le téléviseur, un appui long sur une app propose aussi « Renommer » et « Image d'origine ». Si le téléviseur a plusieurs profils, les noms et les apps masquées sont ceux du profil affiché ; les images valent pour tous les profils.

Masquées sur l'accueil

Installer une app (APK)

Pour installer des apps, autorisez une fois le débogage local sur le téléviseur : Réglages de l'accueil → Système → Débogage local, puis « Toujours autoriser ».

Le fichier est envoyé au téléviseur et installé tel quel (200 Mo au maximum) ; seuls les fichiers .apk sont acceptés, pas les paquets .xapk ni .apks ; l'app apparaît ensuite d'elle-même sur l'écran d'accueil. N'installez que des apps de sources de confiance : les apps installées ainsi sont sous votre responsabilité.

Le code dans l'adresse de cette page est sa seule protection : toute personne qui la connaît, sur le même réseau, peut commander le téléviseur. Ne la partagez pas. Si un téléphone qui l'a ouverte est perdu, régénérez le code sur le téléviseur (Réglages de l'accueil → Page téléphone → Régénérer le code).
