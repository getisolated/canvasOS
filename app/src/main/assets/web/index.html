Installer une app (APK)

Pour installer des apps, autorisez une fois le débogage local sur le téléviseur : Réglages de l'accueil → Débogage local, puis « Toujours autoriser ».

Le fichier est envoyé au téléviseur et installé tel quel (200 Mo au maximum) ; l'app apparaît ensuite d'elle-même sur l'écran d'accueil. N'installez que des apps de sources de confiance : les apps installées ainsi sont sous votre responsabilité.

Le code dans l'adresse de cette page est sa seule protection : toute personne qui la connaît, sur le même réseau, peut commander le téléviseur. Ne la partagez pas. Si un téléphone qui l'a ouverte est perdu, régénérez le code sur le téléviseur (Réglages de l'accueil → Page téléphone → Régénérer le code).
